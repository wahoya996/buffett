**致：** 客户

**来自：** 霍华德·马克斯，TCW

**主题：** 预测的价值，或者“这雨究竟从哪儿来？”

---

做我客户很久的人，都听过我多次对市场预测发表的负面评论。现在，我决定把我能想到的关于预测的坏处一次性说完。

预测的期望值 = 正确预测的价值 x 正确的概率

试图猜测股票或债券走势的动机很容易理解。观察者多年来注意到价格的大幅波动，他们计算了如果在底部买入、在顶部卖出，1美元能变成多少，并将这个结果与“买入并持有”策略的结果进行对比。其中的差异总是大得诱人。

然而，问题在于，除非预测者的尝试或其预测是正确的，否则试图捕捉这些波动没有任何价值。

**但很难做对**

我同意约翰·肯尼思·加尔布雷思（John Kenneth Galbraith）的观点。他说：“我们有两类预测者：那些不知道的，和那些不知道他们不知道的。”如果预测未来很容易，获得卓越的投资结果就会更容易——那样也许每个人都能获得高于平均水平的表现。

**保持平均水平的正确率无济于事**

让我们面对现实吧：我们大多数人预测未来的能力大致相同。麻烦在于，像平均水平一样经常正确，并不能产生优异的结果。

每个投资者都想要高于平均水平的结果。在机构界，相对表现就是“圣杯”（终极目标）。即使在其他地方，目标也是率先看到未来——并采取适当的途径获利。在这些追求中，仅仅和别人一样经常正确显然是没有帮助的。

**即使预测正确，平庸的预测也无济于事**

如果共识预测（市场一致预期）也是正确的，那么仅仅“正确”并不能带来优异的表现。例如，如果对实际国民生产总值（GNP）增长的共识预测是5%，那么股价就会反映这一预期。如果你随后得出结论认为GNP将增长5%，并且你对快速增长的预期促使你购买股票，那么你买的股票价格已经包含了这种增长的预期。如果随后宣布实际GNP增长确实为5%，股价可能不会跳涨——因为市场对5%增长的反应在达成共识预测时就已经发生了。相反，最可能的情况是，在你的持有期内，你将获得股票正常的风险调整后回报。结论是：正确的预测并不一定转化为优异的投资结果。

**高于平均水平的利润来自于正确预测极端事件**

至少二十五年前，人们就注意到股价波动与盈利变化高度相关。所以人们得出结论，准确的盈利预测是在股市赚钱的关键。

然而，后来人们意识到，导致股价变化的不是盈利变化本身，而是出乎意料的盈利变化。看看报纸就知道。有些时候，一家公司宣布盈利翻倍，股价随之跳涨。而另一些盈利翻倍甚至没有引起波澜——或者反而导致股价下跌。关键问题不是“变化了多少？”，而是“这是否被预期到了？”这个变化是否被共识准确预测并因此计入了股价？如果是，公告应该引起很小的反应。如果不是，如果惊喜是令人愉快的（好于预期），公告应导致股价上涨；如果是令人不悦的（差于预期），则股价下跌。

*这引出了一个重要的“第22条军规”（两难困境）。每个人的预测，平均来看，都是共识预测。如果你的预测也是共识，即使它是正确的，也不会产生高于平均水平的表现。优异的表现来自于准确的非共识预测。但因为大多数预测者并不糟糕，实际结果大多数时候都落在共识附近——而非共识预测通常是错误的。就表现而言，回报矩阵看起来是这样的*：

| | **预测** | |
| :--- | :---: | :---: |
| | **共识** | **非共识** |
| **准确吗？** | **是** | 平均 | 高于平均 |
| | **否** | 平均 | 低于平均 |

问题在于，卓越的表现仅来自于正确的非共识预测，但非共识预测很难做出，很难做对，也很难据此采取行动。

1978年当利率处于8%时，大多数人认为它们会保持在那里。利率看跌者预测为9%，看涨者预测为7%。大多数时候，利率都会在这个范围内，没人能赚到大钱。

巨大的利润留给了那些预测长期债券收益率将达到15%的人。但是这些人都在哪儿呢？极端的预测很少是正确的，但正是它们能让你赚大钱。

**大多数预测都是对现状的线性外推**

事实是，大多数预测者预测的未来与近期过去非常相似。一个原因是事物通常按原样继续发展；重大变化不常发生。另一个原因是大多数人不做“零基”预测，而是从当前的观察或正常范围开始，然后他们认为适当加减一点。最后，真正的“巨变”极难预测。

这就是为什么一些最令人难忘的预测是那些外推了当前状况或趋势但却是错误的预测。《商业周刊》可能永远无法摆脱“股票已死”和“债券已死”的阴影。在1990年中的低点，媒体暗示再也不会有人买高收益债券了。1989年，没人认为达拉斯牛仔队能在没有汤姆·兰德里（Tom Landry）执教的情况下获胜，也没人认为湖人队或49人队会输。六年前，东西海岸经济的增长被认为是确定的，而“铁锈地带”的苦难预计将永远持续。就在两年前，乔治·布什还是稳操胜券的。

这就引出了我的副标题：这雨究竟从哪儿来？写这篇备忘录的动机来自于我考虑到今年西部经历的异常多的降水量——以及几个月前的报纸文章。根据这些文章，老树的年轮表明五十年的干旱可能是常态，而迄今为止五年的干旱只是开始。

在干旱开始之前没人预测到它——当时这样的预测可能会有帮助。但就在它可能快要结束的时候，其长期持续的可能性却被揭示了。

**预测者在极端情况下通常错得最离谱**

正是在这些时候——这些拐点——准确的变革预测最有价值，但也最难做出。

以高收益债券为例。在1989年和1990年，随着一系列负面事件接踵而至，它们遭受了持续的打击。有经济衰退、80年代杠杆收购的失败、过度严格监管的实施，以及德崇证券（Drexel Burnham）、哥伦比亚储蓄银行（Columbia Savings）和高管人寿（Executive Life）的倒闭。所有这一切交织在一起——并被大量过度负面的宣传所加剧。

每一个事件都是“滴水刑”（指精神折磨）的又一滴水。每一个都终结了一些投资者保持乐观的能力。因此，每一个都消灭了一个潜在买家，制造了一个卖家，并推动价格走低。

毕竟，什么是市场底部？就是最后一个持有者（即将变成卖家）真的卖出那一刻——也就是价格跌至被证明是低点的时刻。从那时起，由于没有剩下的人转向看空，几条好消息或几个相信价值的买家到来，就足以扭转市场。

**所以你可以看到，悲观情绪的高潮、最低的价格以及预测上涨的最大困难，都同时发生。难怪很难从预测中获利。**

**极端预测难以相信并付诸行动**

假设在1990年10月，一位普通投资者遇到了一位有足够想象力和勇气（因为那是当时所需要的）的人，此人提出了看多高收益债券的充分理由。这位投资者会相信并买入吗？可能不会。

潜在盈利的非共识预测很难相信和执行，**简单原因在于它们远离传统智慧（常识）**。如果一个预测完全符合逻辑且容易被接受，那它就会成为共识预测（其盈利潜力就会小得多）。

所以，如果有人告诉你美国汽车制造商在国内市场的份额将在五年内回到100%，这将是一个对利润有巨大影响的预测。但你可能相信吗？你能据此行动吗？

**未来预测与现在的差异越大，(1) 它偏离共识预测的可能性就越大，(2) 如果它是对的，利润就越大，(3) 相信它并据此行动就越难。**

**你也必须对时机判断正确**

一个能带来利润的预测，不仅必须对事件或方向判断正确，还必须对时机判断正确。

假设你接受了“三大汽车巨头（指美国三大汽车公司）将重新占据美国市场100%份额”的预测，并据此买入了股票。如果一年后他们的市场份额下降了（股价也下跌了）怎么办？你能继续坚持长期持有吗，还是你的决心会动摇？如果五年后他们的市场份额（和股价）没有任何变化呢？你会不会放弃？而当你放弃的时候，是不是正好赶在预测成真前夕？

在扑克牌局中，“怕输的钱赢不了”。在投资中，很难坚持一个不太可能的、非共识的预测并做正确的事……尤其是当时间流逝告诉你这个预测离谱的时候。正如多年前有人告诉我的：“过于超前与错误无异。”

**错误的预测会让你赔钱**

如你所知，我们管理投资组合时，不参考我们对大盘走势的看法。观察者可能会认为这种行为让我们过度暴露在市场波动中，为了保护客户，我们应该根据对未来的预测积极进出市场。

但请记住，只有当我们的预测是正确的（而且比共识预测更经常正确）时，这才会奏效。我认为，因为预测是不确定的，不尝试（预测/择时）更安全。

例如，人们持有股票是因为他们发现长期的预期股票回报很有吸引力。1926年至1987年间，股票的年均回报率为9.44%。但如果你在那744个月中转为持有现金，并错过了表现最好的50个月，你将错过所有的回报。这告诉我，**尝试市场择时是风险的来源，而不是保护。**

如果为了预期未来的表现而能够改变投资金额，那当然很好，但我认为尝试这样做风险太大了。

**做预测是有成本的**

正如上面所建议的，在难以预测的市场中，最好的做法可能仅仅是接受长期的平均表现。

有效市场理论家认为股市预测就像抛硬币一样。如果你有一半的时间是正确的且没有偏差，与买入并持有策略相比，你的预测既无益也无害。但是预测是通过交易来实施的，而交易是有成本的。如果你只有一半的胜率，还要花钱去尝试，那么你的交易越频繁，你的表现就会越低于买入并持有的结果。

**很少有人回顾自己的预测记录**

我们总是读到“我认为股市要涨”。我们从未读到“我认为股市要涨（而且我过去30次预测里对了8次）”或者“我认为股市要涨（顺便提一下，我去年也说了同样的话，结果错了）”。你能想象在不知道击球率的情况下决定雇佣哪些棒球运动员吗？你什么时候见过市场预测者的过往业绩记录？

**大多数预测不考虑其他可能的结果**

我想对于大多数基金经理来说，过程是这样的：“我预测经济会走A路线。如果A发生，利率应该是B。在利率为B的情况下，股市应该走C。在这种环境下，表现最好的板块应该是D，股票E应该涨得最多。”然后在这个预期情景下构建表现最好的投资组合。

但E发生的可能性到底有多大？记住，E是建立在A、B、C和D都发生的基础上的。在预测的世界里，有三分之二的准确率就已经很了不起了。但如果这五个预测每个都有67%的准确率，那么所有预测都正确且投资组合如预期表现的概率只有13%。

如果出现了其他情况怎么办？投资组合会怎样？预测者/投资者如何在投资组合中为他们的预测被证明是错误的这种可能性留出余地（做好应对准备）？

**最后，问问自己“为什么是我？”**

我的意思是“如果有人做出了一个潜在价值很高且大概率正确的预测，为什么要分享给你？”

想想一个正确的市场预测能有多赚钱。只需要很少的资本，一个优秀的预测者在期货市场赚的钱可以是雇主给的薪水的许多倍。好吧，假设他喜欢为别人打工——那为什么他的雇主要把他的预测免费公开，而不是卖掉它们呢？也许你应该问问自己，你是否愿意开支票去买下你正考虑据此行动的那个预测。

格鲁乔·马克思曾说：“任何愿意接纳我为会员的俱乐部，我都不屑加入。”另一种说法可以是：“我绝不会根据别人愿意分享给我的任何预测去行动。”我并不是说没有人拥有高于平均水平的预测能力。相反，正如一位芝加哥大学教授多年前在一篇论文中所写的那样，这类预测者更有可能在圣特罗佩（Saint Tropez）晒太阳，而不是四处求人借用他们的预测。

* * *

关于宏观事件和受到广泛关注的市场（即信息传播相当均匀的所谓“有效市场”）的预测，我们有一个底线。总而言之，我们认为：

*   大多数预测者的能力平平
*   共识预测毫无帮助
*   正确的非共识预测可能带来巨额利润，但也很难持续做出，且很难让人下定决心据此行动
*   实施预测需要成本，且可能成为风险的来源而非回报

这对我们的启示很明确。我们将继续避免基于市场趋势预测的投资组合管理，因为我们认为对于市场趋势，无论是我们还是其他人，都知之甚少。

相反，我们将继续尝试“了解可知之事”——即，在存在偏见、非经济动机占主导地位的市场中工作，在这些市场中，通过努力工作和卓越洞察力是有可能获得优势的。我们将致力于尽可能多地了解少数事物……而不是对每件事都只知皮毛。

可转换证券、高收益债券和困境公司债务都是市场无效性带来异常回报和风险机会的市场。我们将继续以规避风险且**不依赖宏观预测**的方式利用这些机会。

1993年2月15日

……[预测]只适合在炉边作为冬日的谈资。
——弗朗西斯·培根爵士
